## Title

See WorldEdit Before You Press Enter | Selection Overlay 1.8

## English Description

See the selection. Inspect its materials. Preview supported commands before
Enter, then decide what to apply.

This is a preview of WorldEdit Selection Overlay 1.8.0. Check the file versions
on the official pages before downloading: older releases do not include every
feature shown here.

CurseForge: https://www.curseforge.com/minecraft/mc-mods/worldedit-selection-overlay
Modrinth: https://modrinth.com/mod/wg-selection-overlay
WorldEdit: https://www.curseforge.com/minecraft/mc-mods/worldedit

Selection shapes and rulers, block inspection and visual isolation, live
command drafts, cuboid resizing/movement, copied-build rotation/reflection
preview, and the in-game palette editor are demonstrated with the running mod.
Previews and isolation do not change world blocks. Applying bounds edits changes
the selection, not the structure inside it.

The 1.8.0 development build targets Minecraft 1.21.11, 26.1.x and 26.2, with
one universal JAR per loader: Fabric or NeoForge. Not all 1.21 versions.
Local command/clipboard/editing features require compatible singleplayer
WorldEdit; server CUI alone supplies selection data, not clipboard contents.
On NeoForge's 26.1 branch, local WorldEdit requires 26.1.2 or newer.
Fabric also needs compatible Fabric API. Recommended GUI scale: 2x.
