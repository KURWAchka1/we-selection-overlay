# WorldEdit Selection Overlay 1.8.1

- Adds a standalone Fabric client build for Minecraft **1.20.4**, running on Java 17.
- Brings over selection rendering, the ruler, block inspection and isolation, and the overlay palette.
- With WorldEdit **7.3.0** in singleplayer, includes cuboid editing, clipboard previews with typed rotation and reflection, and live previews of supported WorldEdit commands.
- Uses the existing WorldEdit CUI channel. The optional server bridge is not included or extended to 1.20.4.

Use the JAR named `worldedit_selection_overlay-1.8.1-fabric-1.20.4.jar` with Fabric Loader 0.18.4 or newer and Fabric API for 1.20.4. The existing 1.21.11 and 26.x downloads are unchanged. This build is not for Forge or NeoForge.
