# NeoForge 1.21.11 runtime

This module holds the Minecraft 1.21.11 NeoForge implementation of WorldEdit Selection Overlay. It is an input to the [NeoForge universal packager](../WEaddon_neoforge_universal_1.21.11-26.2/), not the recommended distribution artifact.

Use JDK 21 to build it:

```powershell
.\gradlew.bat build
```

The root [README](../README.md) explains the supported versions and the complete release build. The root [verification guide](../TESTING.md) describes the packaged-client game test.
